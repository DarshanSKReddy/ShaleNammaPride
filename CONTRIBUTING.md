# Contributing to Shale Namma Pride

First off, thank you for considering contributing to Shale Namma Pride! It's people like you that make tools for schools better for the community.

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the application, please open an issue in this repository. Include as many details as possible:
- Steps to reproduce the bug
- Expected behavior
- Actual behavior
- Device model and Android version

### Suggesting Enhancements
We are always open to new ideas. If you have an idea for a feature, open an issue explaining what the feature is and why it would be beneficial for the students, parents, or school administration.

### Pull Requests
1. Fork the repository here.
2. Create a new branch (`git checkout -b feature/your-feature-name`).
3. Make your changes.
4. Commit your changes (`git commit -m 'Add some feature'`).
5. Push to the branch (`git push origin feature/your-feature-name`).
6. Create a new Pull Request.

## Code Guidelines
- Follow the official Kotlin coding conventions.
- Make sure to use Jetpack Compose efficiently with state hoisting where applicable.
- Add comments indicating the purpose of complex logic or MVVM operations.
- Avoid hardcoding strings; use `strings.xml`.
